# CSE204 - Design and Analysis of Algorithms

A structured repository containing algorithm implementations, laboratory 
assignments, and problem-solving exercises for the **CSE204 – Design and 
Analysis of Algorithms** course at **SRM University-AP**.

This repository focuses on implementation of fundamental algorithms, analysis of 
time and space complexity, and application of algorithmic design techniques 
using C/C++.
